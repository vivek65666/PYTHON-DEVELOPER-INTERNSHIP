# Task 2 - To-Do List Application

## Description

A simple console-based To-Do List application developed using Python.

The application allows users to add, view, and remove tasks. Tasks are stored in a text file so they remain available even after the application is closed.

## Features

- Add new tasks
- View all tasks
- Remove tasks
- Save tasks to a text file
- Load saved tasks when the application starts
- Handle invalid task numbers
- Handle missing task files

## Technologies Used

- Python
- VS Code
- Python Lists
- File Handling
