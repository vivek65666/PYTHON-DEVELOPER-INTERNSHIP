# Task 5 - Data Analysis on CSV Files

## Objective

Analyze sales data using Python and Pandas.

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed

- Loaded CSV data using Pandas
- Explored the DataFrame
- Checked DataFrame shape and information
- Used `groupby()` and `sum()`
- Filtered rows
- Used `loc[]` and `iloc[]`
- Checked missing values
- Created bar charts
- Analyzed sales by category and region
- Ranked products by sales

## Files

- `sales_data.csv` - Sales dataset
- `sales_analysis.ipynb` - Jupyter Notebook
- `charts/` - Generated charts

## Key Findings

- Electronics generated the highest sales among categories: ₹159,700.
- North generated the highest regional sales: ₹128,000.
- Laptop was the top product by sales: ₹115,000.
- Total sales were ₹201,100.
- Total quantity sold was 93 units.
